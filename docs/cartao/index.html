Como gravar com o app NFC Tools
  1. Toque em Copiar link do cartão (acima).
  2. Abra o NFC Tools e vá em Escrever.
  3. Adicionar um registro → URL / URI → cole o link → OK.
  4. Toque em Escrever e encoste a tag no celular.
    iPhone: encoste no topo do aparelho. Android: no meio das costas.
  5. ⚠️ Não use a opção Bloquear: ela deixa a tag sem poder ser alterada para sempre.
